# AI 初试档案 · Early AI Experiments

五件用 AI 辅助创作的早期网页实验，跨越 2025 年 12 月至 2026 年 5 月。
从手势粒子、互动研学和数字展陈，到网页游戏与点云动效，保留当时的想法和做法。

**在线总入口** · [打开 AI 初试档案](https://greentailtohru-arch.github.io/Early-AI-Experiments/)

创建日期取自原 GitHub 仓库，按 UTC+8 显示。同日作品按创建时间排列。

## 01 · Alpha · 手势粒子

- **英文名称** · Hand-Controlled Particles
- **创建日期** · 2025-12-02

## 保存方式

原仓库的默认分支提交历史和 HTML 源文件收录在 `demos/`。合集首页负责导览与说明。
作品使用原有 CDN 依赖，体验时请保持联网。部分作品需要 WebGL、摄像头或桌面键鼠。

本地预览可在项目根目录运行 `python -m http.server 8000`，然后打开 <http://localhost:8000/>。
